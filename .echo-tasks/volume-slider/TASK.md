# TASK: Живые настройки — VOLUME / MUTE / VIBRATION

## Цель
Слайдер VOLUME и тумблеры MUTE/VIBRATION в SettingsPopup перестают быть декорацией:
значения сохраняются в libGDX Preferences (переживают перезапуск игры) и доступны
любому коду через объект-синглтон GameSettings.

Реального аудио/вибрации в игре пока НЕТ — делаем хранилище + подключение UI.
Аудиомодуль подключится к GameSettings позже, без переделки UI.

## Ограничения
- Ветка echo/work. НЕ коммитить — коммитит дирижёр (echo).
- Комментарии в стиле методички, по-русски (образец — Localization.kt).
- Образец работы с Preferences — Localization.kt (тот же prefs-файл mushroom-hunt-settings).
- Сборка обязана быть зелёной: ./gradlew core:compileKotlin --no-daemon -i > лог 2>&1; смотреть EXIT-код (stdout у градла на d1337 тихий, BUILD-строки писать в лог).
- Стиль UI-кода — как в текущем SettingsPopup.kt.

## Критерии готовности
1. При открытии настроек слайдер/тумблеры показывают СОХРАНЁННЫЕ значения.
2. Изменение любого контрола сохраняется сразу (listener → Preferences.flush()).
3. Перезапуск игры — значения на месте.
4. gradle core:compileKotlin зелёный.
5. GameSettings доступен из любого модуля без передачи ссылок.
